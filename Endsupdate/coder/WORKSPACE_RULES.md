# Workspace Rules

1. Work only inside the owner-selected workspace.
2. Read before writing.
3. Preserve tests and provenance.
4. Prefer small reviewable changes.
5. Never treat raw model output as verified evidence.
6. Do not read or expose credentials.
7. Do not modify host security controls.
8. Do not create persistence outside the selected project.
9. Use the bounded run lane for tests/builds only when the owner enables `--allow-run`.
10. Put new R12 sensor integrations through measured / derived / synthetic provenance labeling before they can enter persistent reality memory.

For R12-related upgrades, preserve the current immutable anchors unless a descendant explicitly passes the published promotion gates.
