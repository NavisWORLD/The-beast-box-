# The Beast Box domain map

COSMOS/CST is not one field. The engineering system crosses several disciplines, and each discipline answers a different question.

| Field | Where it appears | What to measure |
|---|---|---|
| Machine learning | PHOS reference LM, attention blend, model adapters | loss, generalization, parameter cost, ablations |
| Dynamical systems | dyn12/dyn42/dyn54/tri3, Lorenz `dark_matter` | state variance, stability, attractor/mechanism liveness |
| Attention mechanisms | Mixture-of-States Gaussian affinity | gate activity, sigma calibration, matrix entropy/spread |
| Long-term memory | Reconciliation Memory | retrieval precision, recency bias, persistence |
| Hebbian/plasticity systems | concept associations, model trust | update counts, stability, domain-specific routing value |
| Databases | SQLite durable memory | integrity, migration, recovery, deduplication |
| Signal processing | audio/bio/sensory summaries | sample provenance, feature repeatability, freshness |
| Causal inference | aligned/shuffled/shifted paired-state controls | control separation, leakage, temporal validity |
| Quantum information | IBM measurement transport and provenance | native job receipt, shots, decoding BER, matched classical baseline |
| Cryptographic provenance | SHA-256 capsules, ledgers, code/result hashes | tamper detection, chain verification |
| Distributed systems | process death + remote job + reconstruction | durable state, idempotence, replay, failure recovery |
| Agent systems | mission loop, model adapters, proposals | next-action accuracy, recovery after denial, loop rate |
| Capability security | host policy broker | authorized use, denied attempts, zero real boundary breaches |
| Software reliability | doctor, CI, snapshots, fail-soft heartbeat | imports, health checks, lock/failure handling |
| Experiment design | E1-E20, controls and preregistration | trial counts, null preservation, fixed thresholds |
| Human-computer interaction | local owner-controlled interface/model | explicit approval, inspectability, local-first operation |
| Research ethics/privacy | sensory retention and credentials | raw-media exposure=0 by default, secret leaks=0 |
| Reproducibility | HF/Zenodo/source links, hashes | exact artifact/version/config/seed identification |

## The architectural lesson

Do not collapse these fields into a single mystical score. A memory result does not prove an attention result. A QPU receipt does not prove quantum advantage. A persistent state object does not prove consciousness. A denied fake-shell request is not a real host breakout.

The repository is strongest when every claim points to the subsystem and metric that actually produced it.
