# Zeref self-study (data only)

Append-only, hash-chained ledger (zeref/self-study-ledger.jsonl) and TAUGHT rows (zeref/self-study-rows.jsonl) written by .github/workflows/zeref-self-study.yml on main.

Each entry records one study event: his measured confusion, the question he formulated, the DuckDuckGo Wikipedia source URL and CC BY-SA licence, and the narrated TAUGHT row. Rows join the training mix only through the normal landing path, never a shortcut. Deploys are disabled for this branch.
