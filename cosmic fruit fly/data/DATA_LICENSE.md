# Data licensing and claims

`real_flywire_subset.json` is a derived 42-node/95-edge *nonrepresentative* induced subset from [desktop-fly](https://github.com/DenisSergeevitch/desktop-fly), `data/circuit.json`. That upstream project marks its FlyWire-derived data **Creative Commons Attribution–NonCommercial 4.0 (CC BY-NC 4.0)**. Preserve notice and source attribution and do not include it silently in a commercial Beast Box product. Original scientific references: Dorkenwald et al., Nature 2024, DOI 10.1038/s41586-024-07558-y; Schlegel et al., Nature 2024, DOI 10.1038/s41586-024-07686-5.

`ibm_fez_nine_reported_summary.json` reproduces *nine source-reported historical summary records* from `NavisWORLD/The-Cosmic-Davis-12D-Hebbian-Transformer-ver.4.2/workload_decode_summary.json`. Raw device payloads were not independently redecoded in this continuation. Source Git blob: `084282a26bf923f03188a2be4c36f3fb34b09987`.

No real human or animal physiological samples are packaged. `SIMULATED_BIO_STREAM/SINE_FIXTURE_V1` is deterministic mock input, NOT recorded EEG, HRV, GSR, ECG, or physical fly data. The forest-art asset is decorative; the fly's independent 96×64 virtual raster determines observations.
