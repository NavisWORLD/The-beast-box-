| Rewired graph without memory | 0.4750 | 0.0661 | 168 |
| Lesioned graph without memory | 0.4625 | 0.1053 | 172 |

Every arm used the identical environment schedules for each seed, with fixed episode budgets and 26 policy readout coefficients. Connected conditions evaluate extra edges; `neural_edge_ops` and execution milliseconds are recorded per run, so runtime/compute are **not** equalized. The graph does not have equal inference work to the baseline. In all memory-enabled arms the four-key lookup solves the repeat-combination task, so differences between topologies are unidentifiable. Removing memory exposes near-chance accuracy in all crossed conditions. Plasticity effects cannot be identified when the lookup saturates test accuracy. These are *null/inconclusive results*, not a graph advantage.

The fixture has 24 **synthetic** nodes and 96 input edges (post-aggregation count is in the evidence JSON); the full FlyWire connectome is NOT part of this run. The signed count rule is a proxy, not a synaptic conductance estimate. Dataset labels, physiology, motor claims, sentience, consciousness and deployment readiness are outside the evidence.

## Actual gates, failures and exclusions

- Seven isolated tests passed after one test assertion was corrected to account for the expanded nine-arm matrix. The interim failed assertion (`expected 12 runs; got 18`) was a stale test expectation, not a simulator failure.
- SHA mutation and missing metadata are rejected. Replay is deterministic except elapsed wall time. All output SHA-256 files refer to local generated bytes.
- Full Git checkout unavailable: container DNS could not resolve `github.com`; connector access supplied canonical files. No full Beast Box test suite, native CNS event integration, actual `ReconciliationMemory` persistence/retrieval, model swap, network/host actuation, real dataset verification, or release validation was performed.
- Dataset licensing requires review. FlyWire real data were NOT copied into the repository. Real source metadata must be independently reviewed before scientific claims.
- No real experiment video was recorded; no video is presented as execution evidence. The JSONL trace is an actual executed transcript of software actions, not a video.
