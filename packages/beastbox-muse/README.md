# beastbox-muse

Muse 2, Muse S, and Muse S Athena input for The Beast Box. Setup, Bluetooth permissions, browser limits, and troubleshooting live in [docs/MUSE_KIT.md](../../docs/MUSE_KIT.md).

```bash
pip install -e ".[muse]"
beastbox muse simulate --consent --demo
```

Wellness and game signals only. Not a medical measurement, diagnosis, or treatment.
