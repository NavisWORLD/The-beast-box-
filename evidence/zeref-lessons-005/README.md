# zeref-lessons-005

Fresh English, math and world-knowledge lessons for Zeref, one level up from lessons-004
(grade 3-6: bigger multiplication, division, rounding, fractions, percent, area, parts of speech,
irregular verbs, contractions, homophones, idioms, state/world capitals, science, body, space,
history, technology, art, sports, safety).

* Authored for Cory Davis on 2026-10-25 in original wording. No copied text, no scraped dataset,
  no model or teacher transcripts, no private data. Math rows are generated by code and each answer is computed.
* `dialogue.jsonl` is training data. `heldout.jsonl` is NEVER loaded for training (reference only).
* Deduped against every `evidence/*/dialogue.jsonl` and `heldout.jsonl`, Gate v2 sets A and B
  (`scripts/zeref_gate_sets_v2.json`), the chat-eval prompts, set B and the character prompts. Collisions: 0.
* Mixed in additively through `scripts/zeref_chat_corpus.py` EXTRA (cap 0.18, repeat 1, rotating window).
  The promotion gate is unchanged.
* Rebuild: `cd evidence/zeref-lessons-005/tools && PYTHONPATH=../../../models python3 assemble5.py OUTDIR 1400`
