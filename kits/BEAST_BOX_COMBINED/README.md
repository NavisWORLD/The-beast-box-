# Combined Beast Box kit

Start with [EnD](EnD). The release ZIP bundles this guide, the Python wheel and
source distribution, architecture/security/readiness documents, license, and the
unchanged historical model-swap receipt. It includes no model weights or secrets.

In a source checkout, install from the repository root. In a release ZIP, verify
`SHA256SUMS` and install the included wheel. Historical v0.3.2 assets stay separate.
