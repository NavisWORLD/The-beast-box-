What this is

MODEL ≠ MEMORY · MODEL ≠ STATE · MODEL ≠ PROVENANCE · MODEL ≠ AUTHORITY

Beast Box is a local-first runtime. A model supplies text. Memory, software state, routing, and provenance stay outside that model. This page is a static slice of that idea: two brains, one browser-local story. It does not grant tools, reach a private server, or claim the model is conscious.

RAWRPHØS is the native 14,000-step checkpoint rawrphos-native, weight SHA-256 4e45850bfe7b3e2be1d5b12e1956286e1f3f8cfde7b01b70212ad75fbc8610a5. Conversation training used a 384-token window. Longer context is not treated as validated. Greedy decoding only: temperature 0, so a fixed prompt has one token sequence.

    On the preregistered eight-problem pilot, answer-blind revision scored 0/8 for RAWRPHØS 18K and 3/8 for Qwen 0.5B, the same as each model's own initial answers.     How this page runs the 14K weights

    A dyn12 forward exported to ONNX opset 17 and matched PyTorch argmax on sequence lengths 1, 4, 6, and 8. The largest absolute logit gap in that probe was 1.192e-5. This page does not ship that ONNX file. It runs the same dyn12 steps in JavaScript on the unmodified model.safetensors, and it refuses to generate unless the file hash is 4e45850bfe7b3e2be1d5b12e1956286e1f3f8cfde7b01b70212ad75fbc8610a5.
