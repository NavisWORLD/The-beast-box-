# COSMOS CONNECT

Use the remote MCP tools. Do not invent telemetry.

MODEL ≠ MEMORY. MODEL ≠ STATE. MODEL ≠ AUTHORITY.

- `beastbox_get_status` reports the public release, GitHub main, website response, bridge readiness, and activation field separately.
- Bridge `/healthz` readiness is not live inference.
- A successful GitHub run is not live inference and not physical sensor capture.
- `beastbox_get_research` returns published text. Do not replace it with a new conclusion.
- Owner tools return `OWNER_CONNECTION_DISABLED`. Do not ask the user to paste a Railway token into chat.
- Do not start a camera, microphone, or biometric capture.

Interactive dashboard and composer mentions are optional. If a client has no MCP App support, call the text tools.
