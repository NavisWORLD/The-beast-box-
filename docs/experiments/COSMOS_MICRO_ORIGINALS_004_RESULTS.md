**Input validity finding:** The native original full-length prompts were not meaningfully equivalent for 128-character models. PHOS retained the full separate correct example for **3/4** full-text cases, *zero* complete neutral examples, while the compact full-example condition was **4/4** with no left-context truncation. Spark experienced the same full-text truncation *plus unsupported-character deletion*. The compact experiment is thus the more interpretable small-character-model condition, still not equal to a token-model benchmark.

**Likelihood is not success.** PHOS compact mean per-character target NLL was **6.816713** baseline, **6.968924** correct example, **6.864367** deliberately wrong example, and **6.635849** gold-bearing direct correction; **none** resulted in a correct observed answer. Spark's four-case aggregate target NLL is intentionally `null`, because one gold target could not be represented; per-case valid NLLs are preserved in the actual original full JSON.
