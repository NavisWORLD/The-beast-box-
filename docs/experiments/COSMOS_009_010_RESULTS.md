**Important interpretation and preflight sensitivity limits:** The real product pseudo-reviewed training procedure made **one** pairwise update on seed 17 and **zero** on seed 41, leaving seed41's "adaptive" and frozen original router literally identical. In both seeds conventional lexical matching on these invented clear-identifier documents already selected **every correct document**. This experiment therefore did NOT supply a strong adaptive-feedback signal or evidence for beating lexical search; any inference of broad model-independent retrieval superiority is unwarranted. It is a real negative result for this source-bound literal-identifier task, not proof that any other COSMOS configuration can never work.

**Crucial oracle calibration failure:** Under the preregistered strict answer criterion, both public models scored **zero even with the known-correct source handed directly to them**. SmolLM2 typically gave prose not matching the required one-line number. Qwen's outputs were mostly machine-parseable numerals but incorrect three-digit arithmetic. Since an oracle cannot establish that the two frozen generators reliably perform the needed compositional arithmetic, this particular fixture is NOT a capable discriminator of tool-assisted end-to-end answer gains. The lone Qwen adaptive strict hit is also present under frozen R12, with no supported positive treatment effect. A more calibrated future study must freeze NEW seed/task splits and demonstrate model-only oracle success on an independent development set BEFORE inspecting any new held-out model outcomes. Do not silently loosen the original outcome rubric or remove failed cases.

The 8-versus-32 shift is **stored record/distractor size**, not a true increase in transformer token input length; each successful retrieval adds exactly one snippet to a fixed question. Source memory is synthetic disk-based and independently reconstructed for both models; this is NOT a new production live A→B→A model-swap continuity demonstration or autonomous self-generated correction.

**Original preregistered two-model/two-size candidate pattern: FAILED.** Real generated-answer benefit beyond strong conventional lexical and original frozen product routing was NOT demonstrated.
