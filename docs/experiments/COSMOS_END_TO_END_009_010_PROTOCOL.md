# COSMOS 009 + 010 — independently controlled end-to-end generative usefulness and longer sequences

**Status:** research preregistration before first outcome. **Owner:** Cory Davis / NavisWORLD. **No production code, external API calls, secrets, live owner records, training of published models or paid infrastructure.** Both tests use the existing public-repository original implementation and source-pinned public model checkpoints.

## Hypothesis 1 — does the external COSMOS cognitive substrate make actual generated answers more useful?

Test ACTUAL `beastbox.ReconciliationMemory`, `RefractiveMemoryRouter` and `AdaptiveControl`, not a simulation approximating their behavior. Learn one set of adaptive product-router weights from exactly **eight disjoint synthetic pseudo-reviewed routing examples** using the product's actual `AdaptiveControl.fit`. The `reviewed: true` flag represents **simulated fixture supervision**, not real human review or autonomous feedback. Never train on or inspect test query labels to adapt the router. This is *external retrieval improvement*, NOT guaranteed intrinsic model self-correction.

Two independent source fixture seeds **17, 41**, two store sizes: **8 stored records / eight independent queries per seed** versus **32 stored records / sixteen target questions per seed**. This is a **memory-store size** / distractor robustness shift, NOT a transformer token-context extension. Per-seed pairings are exactly identical across all model and router conditions.

Frozen generative models: originally published, full safetensors SHA-256-checked **HuggingFaceTB/SmolLM2-135M-Instruct** and **Qwen/Qwen2.5-0.5B-Instruct**, exactly the previously committed upstream revisions/hashes in COSMOS 003. Both receive their OFFICIAL chat templates, same 18-token deterministic greedy budget, identical per-question prompt except the one selected retrieved context. Full actual named tensor hash before/after must remain identical. Each model's synthetic facts and answers are generated from seed-bound isolated fake notebooks and never enter its weights or durable owner memory.

**Five simultaneously reported conditions for EVERY question**, in this fixed order:

1. **No evidence:** exact same question and response format, but "No notebook record is available." This is a diagnostic lower bound; comparing good retrieval only with no evidence is a *trivial information availability effect* and NEVER establishes superior cognitive architecture.
2. **Conventional lexical:** rank exactly the same stored documents with the product router's lexical similarity score alone. Not a toy random loser.
3. **Frozen original COSMOS R12:** the same original product R12 `WEIGHTS`, no adaptation.
4. **Adaptive COSMOS R12:** the exact product router with weights trained exclusively on separate simulated-training fixture queries. A held-out win over no-evidence alone is NOT novel; comparisons to BOTH lexical and original frozen R12 are required.
5. **Oracle context:** retrieve the evaluator-identified true document regardless of rank. Gives a non-cheating upper bound on ability to use correct evidence and do the arithmetic, not a valid usable retrieval strategy.

Every test question asks the model to **add a small offset to a random documented three-digit seed** for a newly invented notebook. The correct *final result* NEVER literally appears anywhere in the source documents (all seed values are multiples of 10; all query offsets 2..7). This requires elementary numeric answer composition from relevant retrieved evidence rather than copying the final target. The actual task is still simple synthetic tool-assisted arithmetic and cannot establish broad reasoning or external human skill.

**Predeclared strict scorer:** first nonempty generated line must be a bare integer, `FINAL: integer`, bare UNKNOWN or `FINAL: UNKNOWN`, optional trailing period. Exact numeric equality, not a favorable substring somewhere in an explanation. Report answer correctness, retrieval correctness, parse adherence and abstention for EVERY original case, arm, model and store size. Full synthetic input/response text, source model hashes, schema identities and exact original JSON SHA-256 archived without selecting good outputs. Keep all failed answers, routing misses, equal-scoring ties and any model unable to use an oracle record.

The *strict synthetic two-model candidate* pattern requires **adaptive COSMOS at least TWO more genuinely correct generated answers than both lexical and frozen original R12 on both store sizes FOR EACH model, summed over both independent seeds** (4 group comparisons), and an oracle positive bound at least as correct as adaptive and at least 6 correct (each group has 16 or 32 tasks). A single failure/negative/no effect means the preregistered candidate does not hold. The gate is observational and cannot establish general reliable model improvement or scientific novelty.

**Privacy and substrate continuity boundaries:** SQLite records are wholly generated fake data, committed only as experimental receipts; their exact content is reopened via the actual existing memory class, and both models use independently recreated *identically seeded* documents. This is NOT proof of same live owner memory surviving a running production model A→B→A swap; that requires a separate authenticated production/isolated-snapshot test. Both public model checkpoints independently attest original weights. No rights to any owner's connected memory are requested or inferred.

## Hypothesis 2 — does actual native 12D generalize better to longer model-token contexts?

An independent follow-up to real previous COSMOS 006, using fresh unseen seeds **19, 43, 71** (none from 006). Build scratch native **RawrphosLM with its actual dyn12 state/gate/transition implementation** and INDEPENDENTLY TRAIN (i) native dyn12, (ii) original conventional standard attention and (iii) independent trained shuffled-state control. All three start from EXACTLY MATCHING original tensor hashes per seed; use identical synthetic train episodes, minibatches, allocated parameter geometry, batch size 12, 120 AdamW steps, lr 0.003, same CPU numerical choices and no performance-driven hyperparameter tuning, optimizer warm starts, early stopping or selected checkpoint.

Learn only the **three-binding** synthetic episodic value-recall task. Keep 1,536 train, 128 distinct development and 256 distinct held-out three-binding cases; evaluate 128 totally unseen examples EACH for **four-, five- and six-binding** context lengths (genuine increased internal model token sequence lengths, unlike store-size experiment above). Require native state/gate/sigma gradients nonzero, finite and normalized causal attention on ALL three longer lengths, and no change in preceding logits when only future token changes. Never alter the published RAWRPHØS checkpoint; these scratch CPU models are small research replicas of its existing architectural code, not full real conversational-pretraining studies.

Measure all per-seed full correct counts, denominators, accurate test loss, CPU training wall time and both independent standard and shuffled trained controls, alongside optional **inference-only** zero-gate and shuffled-state interventions on the dyn12-trained model. The latter cannot substitute for separately trained baseline models.

Strict multi-length candidate requires native dyn12 to exceed BOTH independently trained controls by at least **three absolute accuracy points IN ALL THREE independent seeds and ALL THREE longer levels (4/5/6)**, while losing **no more than two points** to either control on the original three-binding length. This is deliberately difficult. If not met, report failure/null as a successful experiment rather than tuning seeds afterward.

**Crucial confound:** equal allocated tensor count does NOT equal equal *active* model parameters or FLOPs, because standard attention does not use the allocated state path. The trained controls and three new correlated synthetic seeds do NOT prove a novel 12D intelligence advantage even if favorable. Positive outcomes require independent real-world language/reasoning tasks, more independent samples, FLOP-matched and active-param-matched controls and replication.

## Claim-combination rule

For the joint claim that the *whole external cognitive architecture* produces better generated outputs AND generalizes to longer sequences, preregistered positive results must hold in **both distinct experiments** separately. A memory-routing/gold-document effect must NOT be described as intrinsic generative self-correction or dyn12 superiority. A native scratch model 4-6-binding effect must NOT be described as proven improvement to any original published RAWRPHØS18K conversational checkpoint or the external Qwen/Smol models.

The tests use public-repository GitHub Actions standard CPU runners and immutable archived SHA-bound source receipts, no paid external model API. CI source correctness is not scientific quality evidence. If any runtime fails, preserve the failure; no synthetic results may substitute for actual real pretrained-model generations or independently trained native-controls runs. Review source & full results before merging; no production promotion or automatic deployment of research scripts.
