# R12 Physics Probe 001 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build, preregister, verify, and execute a null-first 12-qubit R12 quantum-echo experiment on IBM Quantum while keeping the existing CST/R12/Zeref architecture immutable.

**Architecture:** Add a pure Probe 001 analysis/mapping module, a live IBM runner, and a fail-closed analyzer. Freeze implementation first, then generate and commit the preregistration packet against that implementation commit, then run synthetic preflight before any IBM submission. Hardware results write only under `experiments/r12-physics-probe-001/` and never mutate protected R12/model assets.

**Tech Stack:** Python >=3.10, NumPy >=2.0, Qiskit >=2.5.0, qiskit-ibm-runtime >=0.47.0, pytest, GitHub Actions, SHA-256/canonical JSON.

**Spec:** `docs/superpowers/specs/2026-08-23-r12-physics-probe-001-design.md` plus `docs/superpowers/specs/2026-08-23-r12-physics-probe-001-amendment-1.md`

- Protected active lineage remains `ZEREF-DAD-SON-TALK-004`.
- Protected checkpoint SHA-256 remains `9944d1d6e69e50f7b4a026a06719a3093a34607bc416ad788c2c658e67b6f55f`.
- Protected R12 state SHA-256 remains `48994584e13d8e2b6fcb21cb682b0b9501af12e2ce8742e99384b604235c9f20`.
- Protected R12 ledger tip remains `78d8698e406c8a60dcf6a9545541fdd74d8b3b250ff0e28a9418bfd3d1f96415`.
- Existing R12 ledger/state/history/manifest and 352-record durable memory are read-only.
- Probe workload is exactly 48 matched blocks x 6 arms x 4096 shots = 1,179,648 planned hardware shots unless IBM service/account limitations prevent completion.
- Discovery and replication each contain exactly 24 valid matched blocks; there is no result-dependent early stopping.
- Real analysis uses exactly 100,000 within-block randomizations per stage, `p <= 0.005`, and `abs(T_stage) >= 0.02`.
- A positive result is at most `ANOMALY_CANDIDATE` / `ANOMALY_CANDIDATE_SAME_BACKEND`; never label it proof of a physical twelfth dimension or new law of physics.
- `IBM_QUANTUM_TOKEN` and optional `IBM_QUANTUM_INSTANCE` must never be printed or persisted.
