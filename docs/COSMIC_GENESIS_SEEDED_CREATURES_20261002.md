# Cosmic Genesis — first additive integration increment

This branch extends the *existing* deployed Beast Cage: it does not replace the
original owner CNS/CST/R12 runtime, permission controls, camera/microphone capture,
existing stateless RAWRPHØS guest route or v1 GBA binary state.

## Versioned identity and scope
\`creature-profile.ts\` is a classical seeded **game-character** generator with
seven creative families, reproducible appearance parameters, five temperament
weights, ten fictional stats and a bounded 500-point budget. Stats use their own
randomness domain, so changing appearance/family never rerolls gameplay.

\`pickAmbientAction\` is a deterministic **quantum-inspired aesthetic** only in
the sense of weighted state choices. It makes **no claim of quantum hardware,
quantum advantage, consciousness, or real-world perception**.

Generated profiles are **not** server-side persistent COSMOS identities and do
not contain model authority, memory, model weights, credentials or private
biometric data. Any browser-only preview must be labeled accordingly.

Future increments will integrate validated generated profiles into the existing
guest page, owner-safe visual avatar, enhanced GBA asset module, and responsive
habitat. Code that doesn't reach applicable CI or native-hardware acceptance must
remain described as implemented or planned rather than verified live.

Ship through separate PR and a deliberate frontend-only deployment; backend and
owner volume require no changes for this increment.
