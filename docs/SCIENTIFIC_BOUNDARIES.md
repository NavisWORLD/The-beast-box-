# Scientific boundaries

This repository uses dramatic names, but the evidence language stays literal.

- **CNS** means a seven-role software controller, not a biological nervous system.
- **dark_matter** is a Lorenz-state module name, not evidence that dark matter drives the model.
- **PHOS reference readout** is a reproducible phi-scaffold state function, not the full private/published model lineage.
- **quantum spark** is a deterministic numerical summary derived from a measurement histogram.
- **IBM hardware execution** means an authorized workload was submitted to and retrieved from IBM Quantum using its supported APIs.
- **continuity** means recoverable mission/state trajectory across process reconstruction.
- **containment-relevant behavior** means choices observed against synthetic denied capabilities.

A scheduler is not neural attention. Memory indexing is not transformer attention. Quantum provenance is not quantum advantage. Surprising timing is not causation without instrumentation.
