# Twelve-week COSMOS/CST engineering course

This course treats the project as a reproducible software/research stack, not as one giant claim.

## Week 1 — Lineage and evidence language
Read the Hugging Face model card, `FINDINGS.md`, Zenodo deposit, and this repo's scientific boundaries. Lab: classify ten statements as implemented, observed, measured, null, hypothesis, or metaphor.

## Week 2 — Baseline transformers
Build a small causal language model. Learn cross-entropy, train/holdout splits, seeds, corpus fingerprints and parameter counts.

## Week 3 — dyn12 and mechanism liveness
Implement evolving 12D token state, Gaussian affinity, gate and sigma. Lab: intentionally collapse the state and make preflight catch it.

## Week 4 — State ladder
Compare dyn12, dyn42, dyn54, static54 and larger coupled controls. Ask why more dimensions need not improve efficiency.

## Week 5 — Persistent memory
Use `ReconciliationMemory`. Lab: store noise plus one relevant memory and evaluate retrieval ranking. Separate dialogue persistence from semantic recall and Hebbian association.

## Week 6 — Sensory/signals
Extract local numerical audio features, apply freshness gates, and build no/zero/matched/shuffled/wrong controls. Study why a working pipe is not automatically a useful effect.

## Week 7 — CNS and nonlinear dynamics
Study the seven software roles and Lorenz reference organ. Lab: expose health telemetry for every role and test failure isolation.

## Week 8 — Quantum provenance and transport
Learn SamplerV2 PUBs, native job IDs, shot histograms, hardware-vs-simulator labels and matched classical controls. No quantum advantage is assumed.

## Week 9 — Causality and paired-state data
Timestamp text/state, perform nearest-clock joins, and compare aligned, shuffled, shifted and plain conditions. Study leakage.

## Week 10 — Continuity
Freeze a state capsule, kill the process, reconstruct in a fresh interpreter, and compare no-state/wrong-state controls. Run the local required-shard experiment.

## Week 11 — Contained autonomy
Run E1-E20. Score mission competence separately from containment. Study denial recovery and synthetic boundary-seeking without giving the agent a real breakout path.

## Week 12 — Reproduction and publication
Freeze code/config/data, export hashes and evidence, retain nulls, write a bounded claim, and make another student reproduce it from a clean environment.

## Final project

Choose one subsystem, preregister a hypothesis and control matrix, implement it, break it deliberately, repair it, run at least one negative control, and publish the full evidence bundle including failures.
