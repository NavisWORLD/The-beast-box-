# OMEGA — Recovery Map (Directive 001)

Generated by `beastbox.omega.recovery.recover_substrate_map`. This is a
**measured inventory**, not a capability claim: CONNECTED means source present,
importable, and a smoke call executed. Declared capabilities without executed
capabilities are not counted.

## Method

- Source presence checked against the working tree.
- Importability checked via `importlib`.
- Executability checked via a minimal smoke call for `dyn12`, `cns7`,
  `hebbian`, `sensors`, `synapse`, `r12` only. All other components report
  DORMANT at best from this probe (present + importable, no smoke execution).

## What this does not claim

Passing this inventory is infrastructure evidence only. It is not evidence of
superior intelligence, consciousness, or general adaptive advantage. The
controlled 12D experiment (`docs/experiments/COSMOS_DYN12_CONTROLLED_006_RESULTS.md`)
reported a **failed** primary advantage test; the OMEGA H2 toy task is a
separate tiny synthetic check and does not overturn that null finding.
