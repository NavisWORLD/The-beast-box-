## What now operates together

There is one published `beast.behavior` kernel, one existing `session.mind`, one
existing browser session key and the same QBEAST. The unpublished earlier visual
draft was preserved locally; its competing runtime was not introduced.

The added graph records up to 128 concepts and 384 links. Each accepted text
observation pairs at most 12 meaningful words, strengthens bounded weights and
decays them every fifth observation. A domain-separated draw from the existing
seed and observation count makes the update reproducible. It is not fresh entropy
or model-weight training. ASCII tokenization and hashed-feature collisions remain
limitations.

Local replies read prior memory before learning the current turn. Authored pattern
prose does not recursively teach itself invented experiences. Behavior recall
uses the actual room/toy/simulated-sound cues and adds at most one to a matching
action's score. The event retains the real recalled words, cues, association and
matrix contribution alongside energy, curiosity, environment and scores.

The same seven actions, seeded selection and versioned behavior record continue
to operate. Explicit keeper encouragement remembers the action actually recorded;
care and training supply bounded feedback. Simulation ticks run at most once per
eight visible seconds, separately from rendering. Hidden time does not fabricate
experiences. No tick grants XP, changes genesis, advances native evolution or
trains a model.

| Variable | Operational meaning |
| --- | --- |
| Behavior energy | Bounded drive: rest +7, explore −2.4, inspect −1.2, play −2, wander −1.5, listen −0.6, idle +0.25 per decision; feed/rest/training add bounded feedback |
| Curiosity | Trait-initialized drive; explore/inspect reduce it by 1.6, other actions increase it by 0.5; always 0–100 |
| Environment comfort/toy/sound/attention | Explicit bounded 0–1 local inputs; the habitat's sound control is SIMULATED, not microphone sensing |
| Room preference | Outcome feedback in −8…8; its score contribution is capped |
| Care energy/XP/bond | Existing care reducer; separate from behavior energy and from authoritative native/signed progression |
| HP, Signal, Memory, Resonance, Agility, Chaos, Stability, Curiosity, Evolution profile stats | Existing domain-separated fictional game ratings; not biological measurements or proof of operational cognition |
| Learned memory | Actual bounded matrix/graph updates and structured feedback, distinct from fictional “Memory” rating |

Spark and Beast Cage use this same core and recorded sprite. Habitat movement and
expression read actual decisions; WebGL failure retains the real same-ID sprite.
The Lab exposes inputs, reasons, memory evidence and an explicitly unsigned local
observation export. The public navigation links to the same existing rooms.
Device motion preferences combine the OS rule and saved setting.

Device writes are serialized under the existing Web Lock, read the latest record,
check identity/genesis and confirm readback. A failed write does not trigger a
saved-success message. A coalesced IndexedDB recovery mirror cannot stall care;
an empty local store can recover it after recipe validation without overwriting
a newer local record. Blocked storage produces an actionable status.

The [.beastjourney format](../apps/beastbox-cloud/docs/DEVICE_JOURNEY.md) carries the
same QBEAST plus unsigned alias/care/memory/behavior. It validates bounded retained
decisions, rolls back failed import and preserves existing same-ID native saves.
Incoming native artifacts remain `unsigned-unverified` until the established
cartridge path validates them. No imported payment/model/device state grants
identity or scientific authority.

## Fresh controlled experiment

[Machine results](../evidence/hf-genesis-001/results.json),
[complete decisions](../evidence/hf-genesis-001/events.jsonl.gz) and
[initial/checkpoint/final states](../evidence/hf-genesis-001/states.jsonl.gz)
include source/code hashes, protocol, genesis digests, failures/limitations and
the preserved source-baseline comparison.

Twelve existing recorded-archive recipes received 12 `grove explore` observations.
Each pair started with identical genome, old Hebbian matrix, sequence counts,
needs, preferences and identity. Only the added association graph was removed
from the ablated branch. Both then received the identical four-room, 360-tick
stimulus schedule. There was no online model or external quantum call.

| Observation | Actual result |
| --- | --- |
| Same-recipe genome and raw RGBA regeneration | 12 / 12 exact; 12 distinct genomes and sprites in this cohort |
| Learned action link recalled in actual decision inputs | 12 / 12 |
| Action histograms changed after graph removal | 12 / 12 |
| Exploration-count paired delta | Mean +2.833; range −1…+23; sample SD 7.158 across 12 fixed pairs |
| Restart at tick 180 → exact subsequent decision/state replay | 12 / 12 |
| Offline brain-slot swap leaves identity, graph and behavior identical | 12 / 12 |
| Extended bounded runs | 3 × 1,200 ticks |
| Complete retained assay decisions | 12,240 |
| Existing God Core source/control assay rerun | 36 repeated geneses; 12 recorded behavioral profiles; 6 feedback/restart checks; 3 long runs |

Memory affected decisions; it did not uniformly improve exploration. The source
comparison has different seeds and includes a simulator cohort with unmatched
bit widths/shot budgets. It cannot isolate a causal quantum-source benefit. These
are descriptive results for a fixed small cohort, not population significance,
neural benchmark replication, biological life or consciousness.

## Reproduce

From the repository root, with Node and Python installed:

```sh
node scripts/audit-huggingface-genesis.mjs --fetch --check
node scripts/audit-creature-genesis.mjs --check
node scripts/experiment-hf-genesis.mjs --check
cd apps/beastbox-cloud
npm ci
npm run typecheck
npm test
npm run build
```

The HF script fetches only manifest-pinned public files and checks their hashes;
it never executes them. The experiment does not require the HF cache after the
source audit has been retained. Decompress the JSONL artifacts to inspect complete
decision and checkpoint inputs. Hardware iPhone/Safari, physical controllers,
independent provider attestations and the separate native embedding/continual
training workflows require their own evidence and are not passed by this assay.
