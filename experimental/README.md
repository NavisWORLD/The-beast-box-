# Beast Box Experimental Research

This directory is the public index for **open experimental work, pre-releases, and engineering/research logs** built on top of the stable Beast Box user surface.

The normal user path remains the root [`README.md`](../README.md) and [`QUANTUM_BEAST_STARTER/`](../QUANTUM_BEAST_STARTER/README.md). Material here may be incomplete, exploratory, null, inconclusive, or superseded. It is published so engineers, researchers, reviewers, and future builders can inspect the actual development trajectory without confusing experimental work with a stable product release.

## Browse

- [`pre-releases/`](pre-releases/README.md) — readable snapshots of experimental systems and completed research branches before they are treated as stable product work.
- [`logs/`](logs/README.md) — chronological engineering/research notes: what was attempted, what failed, what passed, what was preserved, and what remains unresolved.

## Publication rules

Experimental entries should preserve exact branch names, commit SHAs, workflow/run IDs where available, source/provenance boundaries, negative controls, nulls, failures, and conservative classifications. Generated model prose is not scientific evidence. Missing evidence stays missing. Historical data is never silently rewritten to make an experiment pass.

The project terminology `SOUL`, `SoulToken`, and related names refers to software state/event transport and lineage. It does not establish a literal soul, consciousness, sentience, biological continuity, resurrection, quantum advantage, new physics, or a new physical dimension.
